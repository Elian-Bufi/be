El método fue simple y estricto. El legajo es la fuente de verdad. Cada avance es un paquete de trabajo corto, que termina en un pull request con la integración continua en verde. Y cada vez que lo que dice el legajo no se podía o no convenía hacer tal cual, quedó una decisión registrada, con las opciones y lo que se eligió. En números: novecientos cuarenta y tres commits y doscientos ocho pull requests integrados entre el 16 de septiembre y el 26 de octubre. La implementación se hizo con asistentes de IA bajo mi dirección, y está declarado: setecientos treinta commits llevan su coautoría.
