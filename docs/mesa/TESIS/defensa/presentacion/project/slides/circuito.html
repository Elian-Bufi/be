El circuito, de punta a punta

1 · Invitar

Profesional: elige el área; BE crea enlace y código

2 · Aceptar y consentir

Asesorado: acepta el vínculo y autoriza el acceso

3 · Planificar y activar

Profesional: evalúa, fija el objetivo y activa

4 · Registrar

Asesorado: comidas y sesiones; profesional: tomas

5 · Revisar

Profesional: compara lo indicado con lo registrado

6 · Continuar o cerrar

BE aplica el resultado de la revisión

AJUSTAR o SUSTITUIR vuelve al paso 3 · MANTENER sigue en el 4 · FINALIZAR cierra el proceso

Este es el recorrido completo. Uno: el profesional invita y elige el área; BE crea un enlace y un código de un solo uso, y el website dibuja el QR. Dos: el asesorado acepta el vínculo y autoriza el acceso; sin eso, el profesional no ve nada. Tres: el profesional evalúa, fija el objetivo y activa el plan; activar crea una versión que ya no cambia. Cuatro: se registra. Cinco: el profesional revisa. Seis: BE aplica el resultado; según cuál sea, se vuelve a planificar, se sigue igual o se cierra. La versión completa, con carriles, es la lámina B-01 del anexo B.
