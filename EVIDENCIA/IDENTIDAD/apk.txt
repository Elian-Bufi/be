Por qué hay una 0.9.0: el tema oscuro, el isotipo y el ícono nuevos del tramo de identidad visual, y los
cambios de la consolidación, que no tuvo APK propia (0.8.0). Es el mismo commit que la API y el website
desplegados en test. Se construyó con el árbol de trabajo limpio, desde `main`.

Búsqueda de secretos (cantidad de coincidencias, se espera 0 en todas). Se revisan los dos archivos del APK que
llevan código o configuración: el bundle (bytecode de Hermes) y assets/app.config. Las contraseñas y los correos
de las cuentas demo se leen de .env.cuentas-demo y solo se cuentan, nunca se imprimen.
                      bundle   app.config
  JWT_SECRET          0        0
  secreto local       0        0
  token bearer        0        0
  contraseña demo     0        0
  correo demo         0        0

El copy nuevo está en el bundle. Hermes guarda en UTF-16 las cadenas que llevan un carácter no ASCII (como «·»),
así que se buscan codificadas en UTF-16; una búsqueda de bytes ASCII daría 0 aunque estén.
  «Better Everyday»      1   (la bienvenida: «BE · Better Everyday»)
  «Ambiente de prueba»   3
Las cadenas que se buscan en el control de secretos son todas ASCII, así que ese control no tiene esa limitación.
